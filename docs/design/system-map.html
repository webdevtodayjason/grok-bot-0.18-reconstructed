Everything drawn dashed (planned, not built)

  • The titanium.bot names, marketing at titanium.bot, sign‑in at console.titanium.bot, tenants at <slug>.console.titanium.bot, control plane at api.titanium.bot. Today the owner’s instance answers at tb.semfreak.dev.
  • The control plane, accounts, sessions, ledger, provisioning; it would create one instance per client through Coolify’s API, and sign‑in would issue a session the tenant relay accepts.
  • Inbound email, receiving for an @titanium.bot bot address through a webhook receiver in the control plane. Sending already works: Resend, DKIM verified.
  • Restore from box‑store at start, the mirror is written every sync cycle today, but nothing reads it back on boot. Tracked as PERSIST‑1.
  • Nightly snapshots from /data to /mnt/rosa‑storage.
