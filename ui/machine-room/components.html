Frontend handoff · v1

Warmwind, with a machine inside.

The interface is a living stage, not a dashboard grid. Grok Bot’s behavioral power stays intact, while persistent chrome gives way to floating people, conversations, context, and tools that appear only when invoked.

Context ruleAn agent is a direct conversation, not a one-person room. A room is a group chat. Each owns its own files, browser state, and routines.
